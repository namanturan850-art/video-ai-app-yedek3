# AI Video Studio

Local-first AI-assisted YouTube video production tool.

## Goal
A beginner-friendly local application that can:
- accept a topic or reference URL,
- create a new, original German script,
- break it into scenes,
- search/download stock media from Pexels and Pixabay,
- generate narration through AI33.pro,
- create subtitles,
- edit/render with FFmpeg,
- produce a 1920x1080 MP4,
- prepare title/description/thumbnail ideas,
- optionally upload to YouTube after manual approval.

## Important
- The user is not a programmer.
- The app must be operable from a simple browser interface.
- Prefer free/local tools wherever practical.
- Do not copy or lightly rewrite competitor scripts. Reference material is only for high-level concept/style analysis.
- Never commit API keys or secrets to Git.
- AI33.pro API details must not be invented. Keep its integration behind a provider interface until verified API documentation is available.
