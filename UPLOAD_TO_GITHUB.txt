BEGINNER STEPS

1) If your GitHub repository is completely empty:
   - Open the repository in GitHub.
   - Click "Add a README" (or create README.md manually).
   - Commit it to the default branch.

2) Download and unzip this starter package on Windows.

3) In your GitHub repository:
   - Click Add file > Upload files.
   - Drag these files into the upload area.
   - Commit directly to the default branch.
   - If GitHub does not allow folder upload in your browser, upload root files first.
     Codex can create `docs/` and the application folders during Part 1.

4) In Codex:
   - Create/select an environment using this repository.
   - Start a NEW task.
   - Paste the contents of `CODEX_FIRST_TASK.md`.
   - Tell Codex: "Read AGENTS.md, PROJECT_SPEC.md and ROADMAP.md first, then execute CODEX_FIRST_TASK.md. Implement only Part 1."

5) Let Codex complete Part 1 and run tests.

6) Review/commit the changes in Codex/GitHub.

7) Do not start Part 2 until Part 1 works locally.
